# 1. ダンジョンの作成

ロールプレイングゲームと言えばダンジョンです。ここでは、正方形のマス目が並んだタイルマップという考え方でダンジョンを作ります。
ダンジョンを手作業で作ることもできますが、プログラムを使って作ってみたいと思います。

## タイルマップ作成関数

タイルマップ作成関数を、 `create_dungeon.rb` というファイルを作成して、その中に書きます。  
この関数は、指定された幅と高さのタイルマップを穴掘り法アルゴリズムを用いて生成します。壁で初期化されたマップからランダムに掘り進み、通路と「部屋」のような空間を作ります。宝箱とボスの位置もランダムな床タイルに配置されます。

```ruby
require 'json'

TILE_FLOOR = :floor
TILE_WALL = :wall
TILE_TREASURE = :treasure
TILE_BOSS = :boss

TREASURES_COUNT = 3

def generate_tilemap(width, height)
  tilemap = Array.new(height) { Array.new(width, TILE_WALL) }
  stack = []
  start_x = 1 + rand(width / 2) * 2
  start_y = 1 + rand(height / 2) * 2
  stack << [start_x, start_y]
  tilemap[start_y][start_x] = TILE_FLOOR

  while stack.any?
    current_x, current_y = stack.last
    unvisited_neighbors = []

    [[0, -2, :north], [0, 2, :south], [-2, 0, :west], [2, 0, :east]].each do |dx, dy, direction|
      nx, ny = current_x + dx, current_y + dy
      if nx > 0 && nx < width - 1 && ny > 0 && ny < height - 1 && tilemap[ny][nx] == TILE_WALL
        unvisited_neighbors << [nx, ny, direction]
      end
    end

    if unvisited_neighbors.any?
      nx, ny, _direction = unvisited_neighbors.sample
      tilemap[ny][nx] = TILE_FLOOR
      tilemap[current_y + (ny - current_y) / 2][current_x + (nx - current_x) / 2] = TILE_FLOOR
      stack << [nx, ny]
    else
      stack.pop
    end
  end

  floor_tiles = []
  tilemap.each_with_index do |row, y|
    row.each_with_index do |tile_id, x|
      floor_tiles << [x, y] if tile_id == TILE_FLOOR
    end
  end

  if floor_tiles.any?
    treasures_and_boss_locations = floor_tiles.sample(TREASURES_COUNT + 1)
    treasures_and_boss_locations[0..TREASURES_COUNT].each { |x, y| tilemap[y][x] = TILE_TREASURE }

    boss_location = treasures_and_boss_locations.last
    tilemap[boss_location[1]][boss_location[0]] = TILE_BOSS
  end

  return tilemap, [start_x, start_y]
end
```

## 穴掘り法アルゴリズム

穴掘り法では以下のような手順で迷路を作成します。

1. 幅と高さが奇数の2次元配列を用意する
2. 配列の値はすべて「壁」に設定する
3. 開始地点を決める(x, yとも偶数にする)
4. 穴掘り開始
    * 開始基準地点を「部屋」に設定する
    * 4方向をランダムな順番にチェックする
    * チェックする方向の2マス先が「壁」であれば以下の処理を行う
      * チェックした方向の1マス先を「部屋」に設定する
      * 2マス先を開始基準点として 『4. 穴掘り開始』を呼び出す
