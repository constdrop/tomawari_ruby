# 4. ダンジョンの探検

保存されたダンジョンを読み込んで、ダンジョンを探検します。  
また、ステージを進む処理の中にあった戦闘を、ダンジョンでも共用するようにします。

## ダンジョンの読み込み

保存されたダンジョンをゲームの中で読み込むメソッドを、ゲームを開始する前の部分に追加します。
また、ファイルの先頭に`require_relative './room'`を追加します。

```ruby
def load_dungeon(filename = "dungeon_data.json")
  if File.exist?(filename)
    file_content = File.read(filename)
    loaded_data = JSON.parse(file_content, symbolize_names: true)
    rooms = {}
    start_point = [2, 2]
    loaded_data.each do |room_id, data|
      if room_id == :start_point
        start_point = data
        next
      end
      room_id = room_id.to_s
      treasure_item = case data[:treasure_item]
      when "小さなメダル"
        Item.new("小さなメダル")
      when "やくそう"
        HealingItem.new("やくそう", 20)
      when "きずぐすり"
        HealingItem.new("きずぐすり", 50)
      else
        nil
      end
      rooms[room_id] = Room.new(
        data[:x],
        data[:y],
        type: data[:type].to_sym,
        passable: data[:passable],
        treasure_item: treasure_item,
        has_boss: data[:has_boss]
      )
      rooms[room_id].instance_variable_set(:@exits, data[:exits])
    end
    # puts "ダンジョンデータをロードしました。"
    return rooms, start_point
  else
    puts "ダンジョンデータが見つかりません。"
    return nil, nil
  end
end
```

## 戦闘をメソッドにする

これまで、戦闘はステージを進む処理に書いていましたが、戦闘はダンジョンでも行うため、その部分をメソッドにして共用できるようにします。

```ruby
def battle(player, enemy)
  while player.hp > 0 && enemy.hp > 0
    puts "--------------------"
    slow_puts "#{player.name}のHP：#{player.hp}, MP：#{player.mp}"
    slow_puts "#{enemy.name}のHP：#{enemy.hp}"
    puts "--------------------"
    puts "コマンド？"
    puts "1. 攻撃"
    puts "2. 防御"
    puts "3. 逃げる"
    puts "4. アイテム"
    puts "5. 魔法" # 魔法コマンドを追加
    command = gets.chomp.to_i

    case command
    when 1
      player.attack(enemy)
      if enemy.hp > 0
        enemy.attack(player)
      else
        player.gain_exp(enemy.exp) # 敵を倒したら経験値を獲得
        # 10回に1回の確率でやくそうを獲得
        if Random.rand(10) == 0
          player.inventory << HealingItem.new("やくそう", 20)
        end
      end
    when 2
      player.defend
      enemy.attack(player)
    when 3
      slow_puts "逃げることに成功した！"
      break
    when 4 # アイテムの場合
      slow_puts "どのアイテムを使う？"
      player.inventory.each_with_index do |item, index|
        puts "#{index + 1}. #{item.name}"
      end
      item_index = gets.chomp.to_i - 1
      if item = player.inventory[item_index]
        item.use(player, player) # プレイヤーを引数として渡す
      else
        puts "無効なアイテムです。"
      end
    when 5 # 魔法の場合
      slow_puts "どの魔法を使う？"
      player.magic_list.each_with_index do |magic, index|
        puts "#{index + 1}. #{magic.name} (MP: #{magic.mp_cost})"
      end
      magic_index = gets.chomp.to_i - 1
      if magic = player.magic_list[magic_index]
        magic.use(player, player)
      else
        puts "無効な魔法です。"
      end
    else
      puts "無効なコマンドです"
    end
  end
end
```

## ダンジョンの探検メソッド

ダンジョンを探検するメソッドを、ゲームを開始する前に追加します。  
ダンジョンでは、どちらに進むかを番号で選択して進みます。  
部屋に宝箱があったら中身を手に入れられます。
ボスの部屋に着いたらボスと戦います。
その他の部屋では10分の1の確率で強い敵が出てきます。

```ruby
def explore_dungeon(player, rooms, start_point)
  current_room = rooms["#{start_point[0]},#{start_point[1]}"]

  enemies = [
    Enemy.new("スケルトン", 100, 15, 50),
    Enemy.new("ゴースト", 120, 18, 60),
    Enemy.new("ドラゴン", 150, 20, 70),
    Enemy.new("ゴーレム", 180, 25, 80),
  ]

  direction_marks = {
    north: "↑",
    south: "↓",
    west: "←",
    east: "→",
  }

  while current_room
    case current_room.type
    when :treasure
      if current_room.treasure_item
        slow_puts "宝箱を発見した！#{current_room.treasure_item.name}を手に入れた！"
        player.inventory << current_room.treasure_item
        current_room.instance_variable_set(:@treasure_item, nil)
      else
        slow_puts "宝箱は空っぽだった。"
      end
    when :boss
      if current_room.has_boss
        boss = Enemy.new("魔王", 200, 30, 100)
        puts "#{boss.name}が現れた！"
        battle(player, boss)
        break unless player.hp > 0
        current_room.instance_variable_set(:@has_boss, false)
        puts "ボスを倒した！ダンジョンクリア！"
        break
      end
    when :floor
      if rand < 0.1
        battle(player, enemies.sample)
        if player.hp <= 0
          slow_puts "#{player.name}は力尽きた..."
          slow_puts "ゲームオーバー"
          exit
        end
      end
    else
      puts "無効な選択です。"
    end

    current_room.visit

    slow_puts "どちらに進む？"
    directions = current_room.exits.keys
    directions.each_with_index do |direction, index|
      puts "#{index + 1}: #{direction_marks[direction]}"
    end

    input = gets.chomp.to_i - 1
    if directions[input]
      x, y = current_room.exits[directions[input]].split(",").map(&:to_i)

      current_room = rooms["#{x},#{y}"]
    else
      puts "無効な選択です。"
    end
  end
end
```

## `Item`の修正

## 洞窟をダンジョンに変更

洞窟はダンジョンに変更するので、敵を無くして、洞窟に入ったら`load_dungeon`、`explore_dungeon`を実行してダンジョンを探検します。  
また、メソッドにした戦闘開始からの部分を、`battle`メソッドに置き換えます。  

```ruby
# ステージデータ
stages = [
  {
    name: "草原",
    enemies: [
      Enemy.new("スライム", 50, 5, 10, 0.03), # クリティカルヒット率を3%に設定
      Enemy.new("ゴブリン", 70, 8, 20),
      Enemy.new("オーク", 90, 10, 30)
    ]
  },
  {
    name: "森",
    enemies: [
      Enemy.new("オオカミ", 80, 12, 40),
      Enemy.new("スケルトン", 100, 15, 50),
      Enemy.new("ゴースト", 120, 18, 60)
    ]
  },
  {
    name: "洞窟",
    enemies: []
  }
]

# 各ステージを順番にプレイ
stages.each_with_index do |stage, stage_index|
  # ロードしたステージまでは何もしないで次のステージへ
  next if stage_index < current_stage_index

  puts "--------------------"
  slow_puts "#{stage[:name]}に到着！"
  puts "--------------------"

  stage[:enemies].each do |enemy|
    puts ""
    slow_puts "#{enemy.name}が現れた！"

    # 戦闘開始
    battle(player, enemy)

    if player.hp <= 0
      slow_puts "#{player.name}は力尽きた..."
      slow_puts "ゲームオーバー"
      exit
    end
  end

  if stage[:name] == "洞窟"
    rooms, start_point = load_dungeon
    explore_dungeon(player, rooms, start_point)
  end

  slow_puts "#{stage[:name]}をクリア！"
  save_game(player, stage_index + 1) # ステージクリア時に自動でセーブ
end
```
