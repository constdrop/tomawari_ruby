# 3. ダンジョンの保存

ゲームのたびにダンジョンが変わってしまうと困ってしまうので、作成したダンジョンを保存します。

## ダンジョン保存関数

`create_dungeon.rb` ファイルに以下の`save_dungeon`メソッドを作成します。

```ruby
def save_dungeon(rooms, filename = "dungeon_data.json")
  save_data = {}
  rooms.each do |room_id, room|
    save_data[room_id] = room.to_h
  end

  File.open(filename, "w") do |f|
    JSON.dump(save_data, f)
  end
  puts "ダンジョンデータを保存しました。"
end
```

## ダンジョンの作成から保存まで

`create_dungeon.rb` ファイルに以下のようなコードを追加します。
このコードでは、以下のような処理を行います。
* タイルマップの作成
* 生成されたタイルマップを表示
* タイルマップから rooms ハッシュを作成
* rooms をJSON形式で保存

```ruby
# タイルマップの作成
width = 9 # 奇数で指定します
height = 9 # 奇数で指定します
tilemap, start_point = generate_tilemap(width, height)

# 生成されたタイルマップを表示
def display_tilemap(tilemap, tile_properties, start_point)
  tilemap.each_with_index do |row, i|
    row.each_with_index do |tile_id, j|
      if [i, j] == start_point
        print "S"
        next
      end
      case tile_properties[tile_id][:type]
      when :floor then print "."
      when :wall then print "#"
      when :treasure then print "T"
      when :boss then print "B"
      end
    end
    puts
  end
end
display_tilemap(tilemap, tile_properties, start_point)

# タイルマップから rooms ハッシュを作成
rooms = Room.create_rooms_from_tilemap(tilemap)

# rooms をJSON形式で保存
save_dungeon(rooms)

puts "ダンジョンの生成と保存が完了しました。"
```

ここまで作成できたら、`ruby create_dungeon.rb`を実行することで、ダンジョンを作成して保存することができます。
