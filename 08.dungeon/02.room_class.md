# 2. `Room`クラスの作成

タイルマップを作成しましたが、タイルマップの1マスを、宝箱があったり、ボスがいたりする部屋と考えることにします。  
その部屋の属性を持つ`Room`クラスを作成します。

## `Room`クラス

`Room`クラスを`room.rb`というファイルを作成して、その中に書きます。
`Room`は、行(y軸)と列(x軸)でどこの位置かを特定して、それぞれ部屋か壁となります。
部屋には、移動できる方向や、宝箱の中身、ボスの部屋か、一度通ったところか、といった情報を持ちます。
また、クラスメソッドで、タイルマップから部屋のハッシュを作成し、ファイルに保存するメソッドを持ちます。

```ruby
class Room
  ATTRS = attr_reader :x, :y, :type, :passable, :treasure_item, :has_boss, :exits, :visited

  @tile_properties = {
    floor: { type: :floor, passable: true },
    wall: { type: :wall, passable: false },
    treasure: { type: :treasure, passable: true, treasure_item: ["小さなメダル", "やくそう", "きずぐすり"].sample },
    boss: { type: :boss, passable: true, has_boss: true },
  }

  def self.create_rooms_from_tilemap(tilemap)
    rooms = {}

    tilemap.each_with_index do |row, y|
      row.each_with_index do |tile_id, x|
        properties = @tile_properties[tile_id]
        rooms["#{x},#{y}"] = self.new(x, y, **properties)
      end
    end
    
    rooms.each do |key, room|
      x, y = key.split(",").map(&:to_i)

      directions = {
        north: "#{x},#{y - 1}",
        south: "#{x},#{y + 1}",
        west: "#{x - 1},#{y}",
        east: "#{x + 1},#{y}",
      }

      if room&.passable
        directions.each do |direction, xy|
          room.add_exit(direction, xy)
        end
      end
    end

    rooms
  end

  def initialize(x, y, type:, passable:, treasure_item: nil, has_boss: false)
    @x = x
    @y = y
    @type = type
    @passable = passable
    @treasure_item = treasure_item
    @has_boss = has_boss
    @exits = {}
    @visited = false
  end

  def add_exit(direction, room_id)
    @exits[direction] = room_id
  end

  def visit
    @visited = true
  end

  def to_h
    ATTRS.map { |key| [key, public_send(key)] }.to_h
  end
end
```

* `x`: 左から何列目か
* `y`: 上から何行目か
* `type`: 部屋(`room`)または壁(`wall`)
* `passable`: 通ることができる(`true`/`false`)
* `exits`: 方向(`:north`, `:east`, `:south`, `:west`)とその方向に進んだ場合の部屋のID("x,y")
* `treasure_item`: 宝箱に入っているアイテム
* `has_boss`: ボスの部屋(`true`/`false`)
* `visited`: 一度通った部屋(`true`/`false`)
* `create_rooms_from_tilemap`: タイルマップから部屋のハッシュを作成するクラスメソッド。
* `add_exit(direction, room_id)`: 移動可能な方向と部屋を追加するメソッド。
    * `direction`: 方向(`:north`, `:east`, `:south`, `:west`)
    * `room_id`: その方向に進んだ場合の部屋のID("x,y")
* `visit`: 一度通った部屋のフラグを立てるメソッド。
* `to_h`: インスタンスをハッシュに変換するメソッド。
