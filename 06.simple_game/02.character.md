# 2. RPGのキャラクター

RPGのキャラクターには、様々な種類があります。
例えば、勇者、戦士、魔法使い、僧侶など、それぞれ異なる能力や特徴を持っています。
敵もそれぞれの能力や特徴を持っていますので、キャラクターの1つです。
これらのキャラクターをプログラムで表現するには、**クラス** (5章) を用います。


## 「勇者」クラスの例

「勇者」というクラスを定義する場合、以下のような要素を考えます。

* **属性**: 名前、HP、攻撃力、防御力、魔法力など
* **メソッド**: 攻撃する、防御する、魔法を使う、回復するなど

これらの属性やメソッドをクラスとして定義することで、様々なキャラクターを効率的に作成することができます。

### クラスの定義

`class`キーワードを使ってクラスを定義します。

```ruby
class 勇者
  # 属性
  attr_accessor :name, :hp, :attack, :defense, :magic_power

  # メソッド
  def attack(enemy)
    # 攻撃処理
  end

  def defend
    # 防御処理
  end

  def use_magic(enemy)
    # 魔法攻撃処理
  end

  def heal(ally)
    # 回復処理
  end
end
```

### オブジェクトの生成

クラスを定義したら、`new`メソッドを使ってオブジェクトを生成します。

```ruby
# 勇者のオブジェクトを生成
hero = 勇者.new
```

### 属性へのアクセス

オブジェクトの属性には、`.`を使ってアクセスします。

```ruby
# 勇者の名前にアクセス
hero.name = "ゆうしゃ"

# 勇者のHPにアクセス
hero.hp = 100
```

### メソッドの呼び出し

オブジェクトのメソッドは、`.`を使って呼び出します。

```ruby
# 勇者が敵を攻撃
hero.attack(enemy)

# 勇者が仲間を回復
hero.heal(ally)
```


## Character、Player、Enemyクラス

ここまでの説明では、 `勇者` を1つのクラスとして作成しましたが、このRPGのサンプルでは、
キャラクターを表現するために、 `Player` と `Enemy` が `Character` 、を **継承** (5章-3) しています。
キャラクターが持つ共通の機能を `Character` にまとめ、効率的にプログラムを開発することができます。

### Characterクラス

`Character`クラスは、全てのキャラクターに共通する属性（名前、HP、攻撃力など）とメソッド（攻撃する、防御するなど）を定義した **親クラス** です。

```ruby
class Character
  attr_accessor :name, :hp, :attack

  def initialize(name, hp, attack)
    @name = name
    @hp = hp
    @attack = attack
  end

  def attack(target)
    # 攻撃処理
  end
end
```

### Playerクラス

`Player`クラスは、`Character`クラスを継承した **子クラス** です。
プレイヤー特有の属性やメソッドを追加で定義することができます。

```ruby
class Player < Character
  def initialize(name)
    # 親クラスのinitializeメソッドを呼び出す
    super(name, 100, 10)
  end

  def gain_exp(exp)
    # 経験値獲得処理
  end

  def level_up
    # レベルアップ処理
  end
end
```

### Enemyクラス

`Enemy`クラスも、`Character`クラスを継承した **子クラス** です。
敵特有の属性やメソッドを追加で定義することができます。

```ruby
class Enemy < Character
  attr_reader :exp

  def initialize(name, hp, attack, exp)
    # 親クラスのinitializeメソッドを呼び出す
    super(name, hp, attack)
    @exp = exp
  end
end
```
