# 3. RPGの戦闘システム

RPGの戦闘システムは、プレイヤーと敵キャラクターがどのように戦うかを決定する重要な要素です。
戦闘システムによって、ゲームの戦略性や難易度、そして面白さが大きく変わります。

この章で作るRPGでは、以下の要素で構成されるシンプルなターン制バトルシステムを採用します。

* **コマンド選択**: プレイヤーは、自分のターンに「攻撃」「防御」「逃げる」のいずれかのコマンドを選択します。
* **攻撃**: 敵にダメージを与えます。
* **防御**: 敵からの攻撃によるダメージを軽減します。
* **逃げる**: 戦闘から離脱します。
* **HP**: キャラクターの体力を表します。HPが0になると戦闘不能になります。
* **攻撃力**: 攻撃の強さを表します。
* **ダメージ計算**: 攻撃側の攻撃力から防御側の防御力を引いた値がダメージとして与えられます。
* **戦闘不能**: HPが0になったキャラクターは戦闘不能になります。
* **戦闘終了**: 敵を全滅させると戦闘に勝利し、経験値を獲得します。プレイヤーが戦闘不能になるとゲームオーバーになります。

**戦闘の流れ**

1. 敵との遭遇: フィールドを移動中などに敵と遭遇すると、戦闘が始まります。
2. プレイヤーのターン: プレイヤーはコマンドを選択し、行動します。
3. 敵のターン: プレイヤーの行動後、敵が行動します。
4. 戦闘終了判定: プレイヤーまたは敵のいずれかのHPが0になると戦闘が終了します。
5. 勝利/敗北処理: 戦闘に勝利した場合は経験値を獲得し、次のステージに進みます。敗北した場合はゲームオーバーとなります。

**サンプルコード**

```ruby
# 戦闘開始
while player.hp > 0 && enemy.hp > 0
  # 戦闘処理
end

# 戦闘終了判定
if player.hp <= 0
  # 敗北処理
else
  # 勝利処理
end
```

**拡張性**

このシンプルな戦闘システムをベースに、様々な要素を追加して、より戦略的で面白い戦闘システムを構築することができます。
例えば、以下のような要素を追加できます。

* **MP**: 魔法を使うために必要なポイント
* **魔法**: 敵に様々な効果を与える攻撃手段
* **スキル**: 特殊な能力
* **アイテム**: HPを回復したり、状態異常を治したりするアイテム
* **状態異常**: 毒、麻痺、睡眠などの状態異常
* **属性**: 火、水、風などの属性
* **クリティカルヒット**: 通常よりも大きなダメージを与える攻撃
