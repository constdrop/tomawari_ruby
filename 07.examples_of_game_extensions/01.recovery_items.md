# 1. 回復アイテム

ここまでで作ったRPGを遊んでみると、すべて戦った場合、途中でHPがゼロになってしまったのではないでしょうか。
そこで、この章では回復アイテムを取り入れてみます。

## アイテムクラスの作成

まず、全てのアイテムの基底クラスとなる `Item` クラスを定義します。
ここでいうアイテムクラスは、回復アイテムに限らず、持っていることで使うことができ、使うことで減るものすべてを指します。
このクラスは、アイテム名などの共通の属性と、アイテムを使用するためのメソッド `use` を持ちますが、具体的な効果は子クラスで定義します。

```ruby
class Item
  attr_reader :name

  def initialize(name)
    @name = name
  end

  def use(target)
    # アイテムの使用効果は子クラスで定義する
    raise NotImplementedError, "子クラスでこのメソッドをオーバーライドしてください"
  end
end
```

* `name`: アイテムの名前
* `use(target)`: アイテムを使用するメソッド。
    * `target`: 使用対象のキャラクター

## 回復アイテムクラスの作成

次に、`Item`クラスを継承した回復アイテム用の `HealingItem` クラスを定義します。

```ruby
class HealingItem < Item
  attr_reader :effect

  def initialize(name, effect)
    super(name)
    @effect = effect
  end

  def use(target)
    heal_amount = @effect
    target.hp += heal_amount
    puts "#{target.name}は#{@name}を使ってHPが#{heal_amount}回復した！"
    # 最大HPを超えないように調整
    target.hp = [target.hp, target.max_hp].min if target.max_hp
  end
end
```

* `effect`: 回復量
* `use(target)`: アイテムを使用するメソッド。
    * `target`: 使用対象のキャラクター
    * 回復処理を行い、回復メッセージを表示します。

## プレイヤーにアイテムを持たせる

プレイヤーがアイテムを持てるように、`Player` クラスにインベントリ (`inventory`) を追加します。

```ruby
class Player < Character
  attr_accessor :inventory, :max_hp

  def initialize(name)
    super(name, 100, 10)
    @inventory = [] # 初期状態は空のインベントリ
    @max_hp = 100   # 最大HP
  end

  # ... (その他メソッド)
end
```

* `inventory`: 所持しているアイテムを格納する配列
* `max_hp`: プレイヤーの最大HP

## アイテムの追加

ここではまずゲーム開始時にプレイヤーが持っている回復アイテムを追加します。
以下のコードでは、ゲームを開始する処理の後 `player.inventory` に `HealingItem` を追加しています。

```ruby
# ゲームを開始する
puts "冒険が始まる！"
puts "主人公の名前を入力してください："
player_name = gets.chomp
player = Player.new(player_name)

player.inventory << HealingItem.new("やくそう", 20)
player.inventory << HealingItem.new("きずぐすり", 50)
```

ここでは回復アイテムを追加していますが、回復アイテム以外のアイテム（攻撃アイテム、防御アイテムなど）を追加する場合でも、
`Item` クラスを継承した新しいクラスを作成して、同じように追加することができます。

また、例えば敵を倒した後、10回に1回の確率で `"やくそう"` を獲得できるようにすることもできます。
もちろん、敵にも `inventory` 属性を追加すれば、様々なアイテムを獲得できるようにもできます。

```ruby
    # 戦闘開始
    while player.hp > 0 && enemy.hp > 0
      puts "--------------------"
      puts "#{player.name}のHP：#{player.hp}"
      puts "#{enemy.name}のHP：#{enemy.hp}"
      puts "--------------------"
      puts "コマンド？"
      puts "1. 攻撃"
      puts "2. 防御"
      puts "3. 逃げる"
      command = gets.chomp.to_i

      case command
      when 1
        player.attack(enemy)
        if enemy.hp > 0
          enemy.attack(player)
        else
          player.gain_exp(enemy.exp) # 敵を倒したら経験値を獲得
          # 10回に1回の確率でやくそうを獲得
          if Random.rand(10) == 0
            player.inventory << HealingItem.new("やくそう", 20)
          end
        end

      # ... (その他のコマンド処理)

      end
    end
```

## アイテムの使用

戦闘中にアイテムを使用する処理を追加します。
以下のコードでは、コマンドに `"4. アイテム"` とその処理を追加しています。
アイテムの処理では、アイテムリストを表示し、選択したアイテムを使用できます。
`item.use(player)` で、選択したアイテムの効果が発揮されます。

```ruby
    # 戦闘開始
    while player.hp > 0 && enemy.hp > 0
      puts "--------------------"
      puts "#{player.name}のHP：#{player.hp}"
      puts "#{enemy.name}のHP：#{enemy.hp}"
      puts "--------------------"
      puts "コマンド？"
      puts "1. 攻撃"
      puts "2. 防御"
      puts "3. 逃げる"
      puts "4. アイテム"  # アイテムコマンドを追加
      command = gets.chomp.to_i

      case command

      # ... (その他のコマンド処理)

      when 4 # アイテムの場合
        puts "どのアイテムを使う？"
        player.inventory.each_with_index do |item, index|
          puts "#{index + 1}. #{item.name}"
        end
        item_index = gets.chomp.to_i - 1
        if item = player.inventory[item_index]
          item.use(player)
        else
          puts "無効なアイテムです。"
        end
      else
        puts "無効なコマンドです"
      end
    end
```
