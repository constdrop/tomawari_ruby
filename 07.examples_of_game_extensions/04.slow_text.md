# 4. ゆっくりテキスト表示

## 文字を1文字ずつ表示するメソッドを作成する

まず、文字列を1文字ずつゆっくりと表示するメソッドを作成します。
ここでは、`sleep`メソッドを使って文字の表示間隔を調整します。
`$stdout.flush`は、出力バッファをクリアすることで、文字を即座に画面に表示させるためのものです。

```ruby
def slow_puts(text, speed = 0.05)
  text.each_char do |char|
    print char
    sleep speed
    $stdout.flush # バッファをクリア
  end
  puts # 改行
end
```

* `text`: 表示する文字列
* `speed`: 文字の表示間隔 (秒)

## `puts`メソッドを`slow_puts`メソッドで置き換える

ゲーム内で`puts`メソッドを使用している所を、`slow_puts`メソッドで置き換えます。

```ruby
# ... (他のコード)

# 例: ステージ名の表示
slow_puts("#{stage[:name]}に到着！")

# 例: 戦闘メッセージの表示
slow_puts("#{player.name}の攻撃！#{enemy.name}に#{damage}のダメージを与えた！")

# ... (他のコード)
```

## 表示速度の調整

`slow_puts`メソッドの`speed`引数を調整することで、文字の表示速度を変更できます。
`speed`の値を小さくすると表示速度が速くなり、大きくすると表示速度が遅くなります。
ゲームの雰囲気に合わせて調整します。
