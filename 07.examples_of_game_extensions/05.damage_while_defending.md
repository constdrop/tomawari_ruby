# 5. 防御時にダメージを半減

## プレイヤークラスに防御フラグを追加

プレイヤーが防御状態かどうかを管理するために、`Player`クラスに`is_defending`という属性を追加し、
攻撃を受けた時にダメージを変更できるメソッド`take_damage`を追加します。

```ruby
class Player < Character
  attr_accessor :is_defending, :inventory, :magic_list, :max_hp, :mp, :max_mp

  def initialize(name)
    super(name, 100, 10)
    # ... (既存の属性)
    @is_defending = false # 初期状態は防御していない
  end

  # ... (その他メソッド)

  def defend
    super # 親クラスのdefendメソッドを呼び出す
    @is_defending = true
  end

  # 攻撃を受けた時のメソッド
  def take_damage(damage)
    if @is_defending
      damage /= 2 # 防御時はダメージを半減
      @is_defending = false # 防御状態を解除
    end
    @hp -= damage
    puts "#{@name}は#{damage}のダメージを受けた！"
  end
end
```

変更点

* `@is_defending`: 防御状態を表すフラグを追加しました。
* `defend`メソッド: 親クラスの`defend`メソッドを呼び出した後、`@is_defending`を`true`に設定します。
* `take_damage`メソッド: 新しく攻撃を受けた時のメソッドを追加しました。防御状態の場合はダメージを半分にします。また、防御状態を解除します。

## 敵クラスの攻撃メソッドを修正

敵クラスの攻撃メソッドで、プレイヤーの`take_damage`メソッドを呼び出すように修正します。

```ruby
class Enemy < Character
  attr_reader :exp

  def initialize(name, hp, power, exp)
    super(name, hp, power)
    @exp = exp
  end

  def attack(player)
    damage = @attack
    player.take_damage(damage) # プレイヤークラスのメソッドを使用
  end
end
```

## 戦闘処理を修正

プレイヤーが防御コマンドを選択した場合、`defend`メソッドを呼び出すように修正します。

```ruby
# 戦闘開始
while player.hp > 0 && enemy.hp > 0
  # ...
  case command
  when 2 # 防御
    player.defend
    enemy.attack(player)
  # ...
  end
  # ...
end
```
