# 7. 使用したアイテムを減らす

## `Item`クラスの`use`メソッドを修正

`Item`クラス（またはそれを継承している`HealingItem`クラスなど）の`use`メソッドを修正します。ここでは、アイテムを使用したらインベントリから削除するようにします。

```ruby
class Item
  # ... (既存のメソッド)

  def use(target, user) # user引数を追加
    # アイテムの使用効果は子クラスで定義する
    raise NotImplementedError, "子クラスでこのメソッドをオーバーライドしてください"
  end
end

class HealingItem < Item
    def use(target, user)
        # ... (回復アイテムの使用効果)
        user.inventory.delete(self)
        puts "#{user.name}は#{name}を使った。"
    end
end
```

変更点

* `use`メソッドに`user`引数を追加しました。
* アイテム使用後、`user.inventory.delete(self)`でインベントリからアイテムを削除します。
* `puts`メッセージを修正しました。

## アイテムを使用する処理を修正

アイテムを使用する処理で、`use`メソッドに`player`を引数として渡します。

```ruby
# 戦闘中
# ...
when 4 # アイテムの場合
  slow_puts "どのアイテムを使う？"
  player.inventory.each_with_index do |item, index|
    puts "#{index + 1}. #{item.name}"
  end
  item_index = gets.chomp.to_i - 1
  if item = player.inventory[item_index]
    item.use(player, player) # プレイヤーを引数として渡す
  else
    puts "無効なアイテムです。"
  end
# ...
```

変更点

* `item.use(player, player)`と、`player`を引数として渡しています。
