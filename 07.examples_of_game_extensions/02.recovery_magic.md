# 2. 回復魔法

回復のもう1つの方法として、回復魔法を取り入れてみます。

## 魔法クラスの作成

アイテムの時と同じように、基底クラスとなる `Magic` クラスを定義します。
魔法クラスは、回復魔法に限らず、唱えることで効果が発生し、使うことで決まったMPが消費されるものです。

```ruby
class Magic
  attr_reader :name, :mp_cost

  def initialize(name, mp_cost)
    @name = name
    @mp_cost = mp_cost
  end

  def use(caster, target)
    # 魔法の使用効果は子クラスで定義する
    raise NotImplementedError, "子クラスでこのメソッドをオーバーライドしてください"
  end
end
```

* `name`: 魔法の名前
* `mp_cost`: 消費MP
* `use(caster, target)`: 魔法を唱えるメソッド。
    * `caster`: 魔法の使用者
    * `target`: 魔法の対象

## 回復魔法クラスの作成

次に、`Magic`クラスを継承した回復アイテム用の `HealingMagic` クラスを定義します。

```ruby
class HealingMagic < Magic
  attr_reader :effect

  def initialize(name, mp_cost, effect)
    super(name, mp_cost)
    @effect = effect
  end

  def use(caster, target)
    if caster.mp >= @mp_cost
      caster.mp -= @mp_cost
      heal_amount = @effect
      target.hp += heal_amount
      puts "#{caster.name}は#{@name}を唱え、#{target.name}のHPを#{heal_amount}回復した！"
      # 最大HPを超えないように調整
      target.hp = [target.hp, target.max_hp].min if target.max_hp
    else
      puts "#{caster.name}はMPが足りない！"
    end
  end
end
```

* `effect`: 回復量
* `use(caster, target)`: 魔法を使用するメソッド。
    * `caster`: 魔法の使用者
    * `target`: 魔法の対象
    * MPが足りるかチェックし、足りれば回復処理を行います。

### 2. プレイヤーにMPを持たせる

プレイヤーが魔法を使えるように、`Player`クラスにMP (`mp`)と最大MP(`max_mp`)を追加します。

```ruby
class Player < Character
  attr_accessor :inventory, :magic_list, :max_hp, :mp, :max_mp

  def initialize(name)
    super(name, 100, 10)
    @inventory = []
    @magic_list = [] # 魔法リストを追加、初期状態は空のリスト
    @max_hp = 100
    @mp = 50        # MPを追加
    @max_mp = 50    # 最大MPを追加
  end

  # ... (その他メソッド)
end
```

* `mp`: 現在のMP
* `max_mp`: 最大MP

## 魔法の追加

以下のコードでは、ゲームを開始する処理の後 `player.magic_list` に `HealingMagic` を追加しています。

```ruby
# ゲームを開始する
puts "冒険が始まる！"
puts "主人公の名前を入力してください："
player_name = gets.chomp
player = Player.new(player_name)

player.inventory << HealingItem.new("やくそう", 20)
player.inventory << HealingItem.new("きずぐすり", 50)

player.magic_list << HealingMagic.new("ヒール", 10, 30)
```

ここでは回復魔法を追加していますが、回復以外の魔法（攻撃魔法、防御魔法など）を追加する場合でも、
`Magic` クラスを継承した新しいクラスを作成して、同じように追加することができます。

また、例えば一定のレベルになった際に、魔法を追加することもできます。

```ruby
# プレイヤークラスを定義する(Characterクラスを継承)
class Player < Character

  # ... (initializeなどのメソッド)

  def level_up
    while @exp >= @level * 10  # 必要な経験値はレベル * 10
      @exp -= @level * 10
      @level += 1
      @hp += 10
      @power += 2
      @max_mp += 20  # 最大MPを追加
      @mp += 10       # MPを追加
      puts "#{@name}はレベル#{@level}に上がった！"
      puts "HPが#{@hp}、攻撃力が#{@power}になった！"
      puts "最大MPが#{@max_mp}に、MPが#{@mp}になった！"

      # 一定のレベル達したら魔法を覚える
      case @level
      when 10
        player.magic_list << HealingMagic.new("ヒーラ", 15, 50)
        puts "ヒーラの魔法を覚えた！"
      end
    end
  end
end
```

## 魔法の使用

戦闘中に魔法を使用する処理を追加します。
以下のコードでは、コマンドに `"5. 魔法"` とその処理を追加しています。
魔法の処理では、魔法リストを表示し、選択したアイテムを使用できます。
`magic.use(player, player)` で、今回は回復魔法なので、プレイヤーがプレイヤーに対して使うことで効果が発揮されます。

```ruby
    # 戦闘開始
    while player.hp > 0 && enemy.hp > 0
      puts "--------------------"
      puts "#{player.name}のHP：#{player.hp}"
      puts "#{enemy.name}のHP：#{enemy.hp}"
      puts "--------------------"
      puts "コマンド？"
      puts "1. 攻撃"
      puts "2. 防御"
      puts "3. 逃げる"
      puts "4. アイテム"
      puts "5. 魔法" # 魔法コマンドを追加
      command = gets.chomp.to_i

      case command

      # ... (その他のコマンド処理)

      when 5 # 魔法の場合
        puts "どの魔法を使う？"
        player.magic_list.each_with_index do |magic, index|
          puts "#{index + 1}. #{magic.name} (MP: #{magic.mp_cost})"
        end
        magic_index = gets.chomp.to_i - 1
        if magic = player.magic_list[magic_index]
          magic.use(player, player)
        else
          puts "無効な魔法です。"
        end
      else
        puts "無効なコマンドです"
    end
```
