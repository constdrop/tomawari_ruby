# 6. クリティカルヒット

## キャラクタークラスにクリティカルヒット率の属性を追加

キャラクターごとにクリティカルヒットの発生確率を設定できるように、`Character`クラスに`critical_rate`属性を追加します。

```ruby
class Character
  attr_accessor :name, :hp, :power, :level, :exp, :critical_rate

  def initialize(name, hp, power, critical_rate = 0.05) # デフォルト値は5%
    # ... (既存の属性)
    @critical_rate = critical_rate
  end

  # ... (既存のメソッド)
end
```

## 攻撃メソッドを修正

攻撃メソッド内で、クリティカルヒット判定を行い、ダメージを増加させます。

```ruby
class Character
  # ... (既存のメソッド)

  def attack(target)
    damage = @power
    if rand < @critical_rate # クリティカルヒット判定
      damage *= 2 # ダメージを2倍にする
      puts "クリティカルヒット！"
    end

    target.hp -= damage
    slow_puts "#{@name}の攻撃！#{target.name}に#{damage}のダメージを与えた！"
    if target.hp <= 0
      slow_puts "#{target.name}を倒した！"
    else
      slow_puts "#{target.name}の残りHPは#{target.hp}だ！"
    end
  end
end
```

変更点

* `rand < @critical_rate`: `rand` 関数は0以上1未満の乱数を返すため、`@critical_rate`より小さい値が出た場合にクリティカルヒットと判定します。
* `damage *= 2`: クリティカルヒット時はダメージを2倍にします。

## 各キャラクターのクリティカルヒット率を設定

各キャラクターのクリティカルヒット率を調整します。

```ruby
# プレイヤークラス
class Player < Character
  def initialize(name)
    super(name, 100, 10, 0.1) # クリティカルヒット率を10%に設定
    # ... (既存の属性)
  end
end

# 敵クラス
class Enemy < Character
  def initialize(name, hp, attack, exp, critical_rate = 0.05) # クリティカルヒット率を引数で指定
    super(name, hp, attack, critical_rate)
    @exp = exp
  end
end

# 敵の作成例
Enemy.new("スライム", 50, 5, 10, 0.03) # クリティカルヒット率を3%に設定
```
