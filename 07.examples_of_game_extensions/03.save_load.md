# 3. セーブ・ロード機能

## セーブデータの形式を定義する

まず、どのようなデータをファイルに保存するかを決定する必要があります。
ここでは、プレイヤーのステータス、インベントリ、魔法リスト、ステージ進行状況を保存することにします。
これらのデータをHash形式で保存し、`JSON`形式に変換してファイルに保存します。

```ruby
require 'json'

def create_save_data(player, current_stage_index)
  {
    player: {
      name: player.name,
      hp: player.hp,
      max_hp: player.max_hp,
      power: player.power, # 不具合が見つかったため attack を power に変更しています。Characterクラスも変更してください。
      level: player.level,
      exp: player.exp,
      mp: player.mp,
      max_mp: player.max_mp,
      inventory: player.inventory.map { |item| { name: item.name, class: item.class.to_s, effect: item.respond_to?(:effect) ? item.effect : nil } },
      magic_list: player.magic_list.map { |magic| { name: magic.name, mp_cost: magic.mp_cost, class: magic.class.to_s, effect: magic.respond_to?(:effect) ? magic.effect : nil } }
    },
    current_stage_index: current_stage_index
  }
end
```

## セーブ処理の実装

セーブ処理では、`create_save_data`で作成したHashデータをJSONに変換し、ファイルに書き込みます。

```ruby
def save_game(player, current_stage_index, filename = "save_data.json")
  save_data = create_save_data(player, current_stage_index)
  File.open(filename, "w") do |file|
    JSON.dump(save_data, file)
  end
  puts "ゲームをセーブしました。"
end
```

## ロード処理の実装

ロード処理では、保存したファイルからJSONデータを読み込み、Hash形式に変換し、プレイヤーのステータスなどを復元します。

```ruby
def load_game(filename = "save_data.json")
  if File.exist?(filename)
    File.open(filename, "r") do |file|
      save_data = JSON.load(file)
      player_data = save_data["player"]
      current_stage_index = save_data["current_stage_index"]

      player = Player.new(player_data["name"])
      player.hp = player_data["hp"]
      player.max_hp = player_data["max_hp"]
      player.power = player_data["power"]
      player.level = player_data["level"]
      player.exp = player_data["exp"]
      player.mp = player_data["mp"]
      player.max_mp = player_data["max_mp"]

      player.inventory = player_data["inventory"].map do |item_data|
        item_class = Object.const_get(item_data["class"])
        item_class.new(item_data["name"], item_data["effect"])
      end

      player.magic_list = player_data["magic_list"].map do |magic_data|
        magic_class = Object.const_get(magic_data["class"])
        magic_class.new(magic_data["name"], magic_data["mp_cost"], magic_data["effect"])
      end

      puts "ゲームをロードしました。"
      return player, current_stage_index
    end
  else
    puts "セーブデータが見つかりません。"
    return nil, 0
  end
end
```

## ゲームへの組み込み

ここでは、ゲームの開始時にロード処理を、ステージをクリアしたときにセーブ処理を呼び出すようにします。
ゲーム開始時にロード処理を実行するには、ゲーム開始時の処理を以下のように変更します。

```ruby
# ゲームを開始する
puts "冒険が始まる！"
puts "1. 新規ゲーム"
puts "2. ロード"
command = gets.chomp.to_i

case command
when 1 # 新規ゲーム
  puts "主人公の名前を入力してください："
  player_name = gets.chomp
  player = Player.new(player_name)
  current_stage_index = -1

  player.inventory << HealingItem.new("やくそう", 20)
  player.inventory << HealingItem.new("きずぐすり", 50)

  player.magic_list << HealingMagic.new("ヒール", 10, 30)
when 2 # ロード
  player, current_stage_index = load_game()
  if player.nil?
    # ロード失敗時は新規ゲームを開始
    puts "主人公の名前を入力してください："
    player_name = gets.chomp
    player = Player.new(player_name)
    current_stage_index = -1
  end
else
  puts "無効なコマンドです"
  exit
end

if current_stage_index == -1
  player.inventory << HealingItem.new("やくそう", 20)
  player.inventory << HealingItem.new("きずぐすり", 50)
  
  player.magic_list << HealingMagic.new("ヒール", 10, 30)
end
```
